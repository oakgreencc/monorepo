# Common failures

| Symptom                                                       | Cause and fix                                                                                                                                                              |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `oakgreen: <tool> not found` (exit 127)                       | The tool's package is missing: `npm install -g oakgreen` (brings every tool).                                                                                              |
| `graft doctor` fails on App credentials or installation       | The App was not created or not installed on this repo: back to [human-steps.md](human-steps.md#github-app-and-repository).                                                 |
| `! labels on <repo>: …` from `oakgreen setup`                 | graft cannot write labels: the App lacks Issues: write or is not installed on the repo. `graft doctor`, then re-run setup.                                                 |
| `cambium status`: `skipped: no usable cambium config`         | The config is missing or not JSON: `oakgreen setup`, or fix the JSON it names.                                                                                             |
| `cambium heartbeat`: `no heartbeat` right after start         | One tick has not finished yet. Wait `tickSeconds` (30 s) and re-run the doctor. Still failing: `~/.oakgreen/cambium/logs/cambium.launchd.err.log`.                         |
| `oakgreen start cambium` skips cambium                        | `cambium install` refused, usually no config at the default path. With a non-default config: `cambium install --config <file>`, then `oakgreen start cambium`.             |
| `Bootstrap failed: 5: Input/output error`                     | A bootstrap while the old process was still stopping. `oakgreen reload <service>` waits for it; use that instead of raw `launchctl`.                                       |
| `oakgreen start mycelium` skips mycelium                      | No source configured or `repo` missing in the `mycelium` section of `~/.oakgreen/forest.json`.                                                                             |
| `curl …:4318/v1/traces` refused                               | otelcol not running: `oakgreen services otelcol`, `~/.oakgreen/cambium/logs/otelcol.log`; often `otelcol-contrib` is not in the agent's `PATH` (`/opt/homebrew/bin` etc.). |
| No traces in canopy                                           | cambium's agent lacks `OTEL_EXPORTER_OTLP_ENDPOINT` (re-installed?), or `engine` is `legacy`, which is not traced.                                                         |
| Workers fail with `claude: command not found`                 | The agent's `PATH` was captured before Claude Code was installed: `cambium install`, then `oakgreen reload cambium`.                                                       |
| `oakgreen services` prints nothing useful on Linux or Windows | Services are launchd agents, macOS only. graft, canker and deadwood still work.                                                                                            |
